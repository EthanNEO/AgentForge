# AgentForge 参赛演示彩排稿

主线任务为 CSV 订单统计工具。观众跟随一个 Run，从需求输入、计划确认、并行执行和真实测试，走到可查看依据的交付结论。建议录制约 4 分钟，实际等待段剪辑时保留 Run ID，并用字幕注明时间跳转。

> ⚠️ **已被取代（历史备选）**：本彩排稿基于预置软件交付场景。**主演示请用 [`演示脚本-自愈主线.md`](演示脚本-自愈主线.md)**。工作台已移除场景选择器（`createPlan` 硬编码 `scenario:"custom"`），预置场景现仅经 API 触发（`POST /api/run`，`scenario:"software_delivery"`，可用 `output/run_delivery.py`）；下文已修正不存在的 UI 操作。引用的历史 Run 仍存在，但均为整改前样本。

## 彩排准备

- 启动本地服务并确认工作台显示在线推理模式。演示任务可沿用 `output/run_delivery.py` 中的订单统计需求。
- 录制前选一条新版本成功 Run，先确认监控台的「交付评审」能逐条展示，并打开至少一个证据文件。现场若遇到外部模型波动，直接打开预先保存的 Run 并说明录制时间。
- 逐条评审的在线样本为 [20261112-121242-c4d860cd](http://127.0.0.1:8000/?run=20261112-121242-c4d860cd)。六个节点均一次通过，评审覆盖 6 项。该样本保存了每项的理由和文件链接。后续新 Run 还会在监控台显示完整需求描述。
- 历史在线重试样本为 `20261109-153104-9a872df2`，监控地址 `http://127.0.0.1:8000/?run=20261109-153104-9a872df2`。第一次评审提出空数据标记缺口，第二次评审通过。画面只陈述可见的评审与重试结果，源码是否修复需另查。
- 上一版三次连续成功的运行编号、耗时、测试与产物核验见 [11 月 10 日交接记录](HANDOFF-2026-11-10.md)。
- 若要展示图片输入，可单独打开历史在线视觉样本 `20261109-143106-3495d8d6`，查看附件与模型输出。主线时间不足时留作备选。
